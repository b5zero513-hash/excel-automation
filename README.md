# Excel業務自動化ツール

第1版の仕分けデモです。販売HPからリンクする独立したReact・TypeScript・Viteアプリとして構成しています。

## 開発

必要環境: Node.js 24以上、npm。

```sh
npm ci
npm run dev
```

本番用静的ファイルの生成とローカル確認:

```sh
npm run build
npm run preview
```

## 使い方

1. `.xlsx` ファイルまたはサンプルを選ぶ。
2. 対象シート、見出し行、仕分け列を選ぶ。
3. プレビューで件数と生成シート名を確認し、仕分けを実行する。
4. 加工済みファイルをダウンロードする。

元のブック内の全シートは残り、対象シートの元データも維持されます。選択した表の値ごとにシートを追加します。分割シートは列幅・セル書式・行の高さを引き継ぎます。入力はブラウザ内で処理し、アップロード・アカウント・履歴・ローカル保存は行いません。静的ホスティング上ではサンプルファイルだけを同一オリジンから取得します。

## 対応範囲と上限

`.xlsx` の通常の表データを対象にします。ファイルは10 MiB以下、ZIP内の合計展開サイズは100 MiB以下、ZIP項目数は2,000以下、1シートは100,000行・200列以下、1ブックは100シート以下、分割先は50シート以下です。

マクロ、暗号化ブック、数式、結合セル、画像・グラフ・ピボット・外部リンクを含むブック、ZIP64形式は処理しません。入力と出力のシート・セルデータは保ちますが、Excelのすべての機能・表示を完全に保持するものではありません。対応外の構造が見つかった場合は、出力前に理由を表示して停止します。

## 確認

- `npm run verify:exceljs`: 日本語シートと列名、`.xlsx` 読込、仕分け、複数シート出力、再読込。
- `npm test`: Excel処理関数の回帰確認。
- `npm run build`: TypeScriptとブラウザー用バンドルの確認。

Must要件、根拠ID、受入テストIDは `docs/SRS.md`、入力境界は `CONSTRAINTS.md` に記録しています。
