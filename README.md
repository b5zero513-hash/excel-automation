# 店舗売上Excel 集計デモ

架空のベーカリー「まちのパン工房」を題材に、各店舗の売上Excelをまとめて集計するブラウザーアプリです。5店舗から届くファイルを一度に選ぶと、全店合計・店舗別・カテゴリ別の売上を確認でき、3シートの集計済みExcelをダウンロードできます。

## 開発

必要環境: Node.js 22.17.0以上、npm。

```sh
npm ci
npm run dev
```

本番用ファイルの生成・ローカル表示:

```sh
npm run build
npm run preview
```

## Cloudflare Pages

Git連携でPagesプロジェクトを作成し、次の値を設定します。

| 設定 | 値 |
| --- | --- |
| プロジェクト名 | `excel-automation` |
| ルートディレクトリ | `/`（リポジトリ直下） |
| 本番ブランチ | `main` |
| ビルドコマンド | `npm run build` |
| ビルド出力ディレクトリ | `dist` |

Node.jsはルートの `.node-version` で固定します。環境変数やPages Functionsの設定は不要です。

## 店舗売上の集計

1. 各店舗の `.xlsx` をまとめて選ぶか、「サンプル5店舗で集計を試す」を選びます。
2. アプリが売上行を統合し、全店舗合計・店舗別売上・カテゴリ別売上を表示します。
3. 集計済みExcelをダウンロードします。ファイルには「全店舗統合データ」「店舗別集計」「カテゴリ別集計」の3シートが入ります。

必要な見出しは「売上日、店舗コード、店舗名、商品コード、商品名、カテゴリ、販売数量、単価、売上金額、支払方法」です。列順は入れ替えできます。全ファイルの売上日をそろえ、1ファイルにつき1店舗のデータを入れてください。

## サンプル

「サンプル5店舗で集計を試す」から京橋・天満・都島・守口・寝屋川の架空データを読み込み、その場で結果まで確認できます。ファイルは `public/samples/sales/` にあります。元の仕分けデモ用サンプルも残しています。

```sh
npm run create:sales-samples
```

## ファイルの扱いと上限

入力ファイルはブラウザー内で読み取り、集計します。利用者が選んだExcelをサーバーへ送信したり、ローカルストレージへ保存したりしません。サンプルExcelは静的ホスティングから読み込みます。

一度に最大10ファイル、1ファイル10 MiB以下、選択ファイル合計50 MiB以下、統合後100,000行以下です。通常の値が並ぶ `.xlsx` を対象とします。数式、結合セル、画像・グラフ・ピボット・外部リンク、マクロ、暗号化ブックなど既存の対象外条件に該当するExcelは処理を止めます。出力がExcelのすべての機能や表示を保持するとは限りません。

## Excel仕分け

画面上部の「Excel仕分けも試す」から、既存の仕分け機能も利用できます。選んだブックを変更せず、指定列の値ごとにシートを追加したExcelを作成します。

## 確認

- `npm test`: 売上集計・Excel出力と既存の仕分け関数を確認。
- `npm run verify:exceljs`: ExcelJSの日本語データ読込・書出しを確認。
- `npm run build`: TypeScriptと静的配信用ファイルを生成。
